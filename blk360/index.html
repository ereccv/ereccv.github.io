BLK360 – Workflow Import to CAD

A step-by-step record of taking a Leica BLK360 scan from the scanner, through registration, into AutoCAD as an RCP point cloud, and then using the same data to check wall flatness, plumbness and room dimensions.

CategoryCAD Drafting / Scan-to-CAD
RoleCAD drafting & technical documentation (contributor)
SoftwareBLK360 app, Cyclone REGISTER 360, AutoCAD, ReCap, FARO BuildIT, CloudCompare

Project Overview

Why a scan belongs in a CAD workflow.

The BLK360 captures a room as a point cloud. Once registered and published as RCP, the scan can be attached in AutoCAD, where the plan is traced with polylines and dimensioned. The same scan can be exported to E57 and analysed in FARO BuildIT or CloudCompare to check wall flatness and plumbness, which matters before preparing tile shop drawings.

The workflow was tested on an Office Bathroom Test 1 scan. The notes were kept in a shared team notebook; this page reorganises them into one sequence with the original steps and terminology.

At a glance

  • Scanner: Leica BLK360
  • Registration: Cyclone REGISTER 360 (BLK Edition)
  • CAD format: RCP, attached in AutoCAD
  • Analysis format: E57 (from ReCap export)
  • Checks: squareness, flatness, plumbness, room dimensions

01

Setting up

Prepare the BLK360 and connect to it from the laptop.

  1. Turn on the BLK360; a green light shows around the bottom.
  2. Connect the BLK Wi-Fi network to your laptop or computer.
  3. Open the BLK360 manager, then click Find and Connect to the device.
02

Scanning

One scan per room, started from the scanner button or a mobile device.

  1. Connect the scanner to the tripod.
  2. Press the button to start the scan.
  3. Once the scan is done, the bottom turns green.
  4. One scan per room.
03

Import to Data Storage App

Move the scanned data off the scanner and onto the computer.

  1. Connect the BLK Wi-Fi and go to the BLK manager app.
  2. Click Find and Connect to the device.
  3. Check the file that you scanned and hit Download.
04

App Navigation & Sync

Open the project, clean up the scan and sync it to the registration software.

  1. Click the current project you need to work on.
  2. Check whether anything needs to be cleaned, erased or removed.
  3. From the mobile device, click Sync Server so it syncs to the registration software (Cyclone REGISTER 360).
  4. Click Add Project. Note: Add Project previews all the projects on the mobile device.
  5. Note: the more projects you have, the longer the sync takes.
05

Registration & Export to RCP

Register the scans in Cyclone REGISTER 360 (BLK Edition) and publish a point cloud for CAD.

  1. Click Field 360, then choose Test Connect, and import. No targets were used in the tutorial example.
  2. Tick Auto Cloud, then click Import.
  3. After import, the next step is Review and Optimize. Options: TruSlicers, Bundle Cloud and SiteMap.
  4. Click Optimize Bundle. When happy, click Finalize, then choose Accept and Publish.
  5. Go to the Publish Options and convert to RCP for CAD software.
06

Plotting to CAD

Attach the RCP scan in AutoCAD and trace the plan.

  1. Open AutoCAD.
  2. Type ATTACH in the command prompt.
  3. Select the BLK360 RCP file, then click Open / Insert.
  4. Check the units of your CAD model: type UNITS in the command prompt and select the unit to prepare (metre was selected).
  5. Trace the laser plan using the Polyline command and add dimensions.
07

Wall Flatness & Plumbness Workflow

Using the scan to investigate walls before tile shop drawings, tested on the Office Bathroom Test 1 scan. Notes recorded 16 Feb 2023.

Preparing the scan

  1. Investigate the RCP file for the given scanned data and select the RCS/RCP file in your folder.
  2. Decide where a reference can be placed on the wall, from floor to wall.
  3. Check the walls for protrusions, unevenness or unfinished masonry.
  4. In AutoCAD, type ATTACH, open the file, crop in 3D, then use the top view and crop again to make an elevation where the floor and wall can be seen.
  5. Convert .rcp to .e57 using ReCap Export (or the Leica app), cutting the section first so the inside of the wall can be analysed.

FARO BuildIT: flatness

  1. Launch FARO BuildIT and check the measurement units (metric, mm).
  2. File &gt; Import &gt; Import E57 File Clouds.
  3. Select the elevation with the Extract Surface tool (Plane, point cloud, constraint, tolerance 1).
  4. Open Surface Deviation Analysis, set the colour scale and Create annotations with a tolerance of +1.5 / -1.5, then Apply.
  5. Set Surface Annotation to read the flatness values. Red shows where the wall is not flat; green where it is flat.

FARO BuildIT: plumbness

  1. Repeat the flatness workflow, then check the extracted plane faces the right way (Manager > Surface > Shaded, Surface normal).
  2. Constraint > Constraint Tangent > pick axis, set (0,0,1) > Apply.
  3. Light grey shows the positive side of the surface and dark grey the negative side; the positive side is needed.
  4. Set the same values as on the wall flatness workflow and apply to each surface.

CloudCompare: plumbness by verticality

  1. Open the .e57 file in CloudCompare (exported from ReCap).
  2. Select the SOR tool to reduce and clean unnecessary points so the focus is the wall surface.
  3. Tools > Other > Compute Geometric Features; tick Verticality.
  4. Choose the preferred colour scale; the bar on the right shows whether the wall is plumb.
✓

Outcomes: Office Bathroom Test 1

  • Wall squarenessChecked with reference planes; the squareness of the wall was precise.
  • Flatness / plumbnessProtrusions and dips found; the deviation map showed the wall needing repair or construction to be plumb and ready for tiles.
  • Room dimensionsScan scaled accurately; door height and width read as 2.09 m and 0.78 m, for preparing shop drawings.

Notes from the testing

  • The files used were RCS, not RCP.
  • The wall inside must be worked out by cutting the scan; only the outside would otherwise be measured.
  • Surfaces are hard to navigate in BuildIT when they are not regular in shape; BuildIT needs a subscription.
